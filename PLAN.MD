# 90-Day Software Architect Roadmap

Goal: Transition from Java/Spring Boot developer to architect.

Time: 2 hours per day, 13 weeks.

## Month 1: Engineering Foundations

### Week 1 - Algorithms and DSA
- [ ] Big-O complexity
- [ ] Arrays, strings, hash maps
- [ ] Two pointers and sliding window
- [ ] Binary search and sorting
- [ ] Stacks, queues and linked lists
- [ ] Solve 8-10 Java problems
- [ ] Explain complexity and trade-offs

### Week 2 - Advanced Java
- [ ] JVM memory and garbage collection
- [ ] Java Memory Model
- [ ] Concurrency and thread safety
- [ ] ExecutorService and CompletableFuture
- [ ] Virtual threads
- [ ] Concurrent collections
- [ ] Benchmark concurrent execution

### Week 3 - System Design Fundamentals
- [ ] Functional and non-functional requirements
- [ ] Scalability, availability and latency
- [ ] Load balancing
- [ ] Caching strategies
- [ ] Database indexing, replication and sharding
- [ ] CAP theorem and consistency
- [ ] Design URL shortener and rate limiter

### Week 4 - Spring Boot and DSA
- [ ] Spring IoC and proxy internals
- [ ] Transaction propagation and isolation
- [ ] JPA performance and connection pooling
- [ ] API versioning and idempotency
- [ ] Circuit breakers, retries and timeouts
- [ ] Trees, heaps and graphs
- [ ] Optimize a Spring Boot API

## Month 2: Distributed and Cloud-Native Systems

### Week 5 - Apache Kafka
- [ ] Kafka architecture and partitions
- [ ] Producers and acknowledgements
- [ ] Consumer groups and offsets
- [ ] Ordering and delivery semantics
- [ ] Idempotent processing
- [ ] Retries and dead-letter topics
- [ ] Build Kafka microservices

### Week 6 - Distributed Transactions
- [ ] ACID, BASE and eventual consistency
- [ ] Saga orchestration and choreography
- [ ] Transactional outbox and CDC
- [ ] Idempotency and duplicate events
- [ ] Compensation and recovery
- [ ] Event sourcing
- [ ] Implement a payment transfer workflow

### Week 7 - Google Cloud Platform
- [ ] GCP projects and IAM
- [ ] VPC and networking
- [ ] Cloud Run versus GKE
- [ ] Cloud SQL, Storage and Pub/Sub
- [ ] Load balancing and API Gateway
- [ ] Logging and monitoring
- [ ] Deploy Spring Boot to Cloud Run

### Week 8 - Kubernetes
- [ ] Cluster architecture
- [ ] Pods, deployments and ReplicaSets
- [ ] Services, ingress and DNS
- [ ] ConfigMaps and Secrets
- [ ] Health probes and resource limits
- [ ] Autoscaling and rolling updates
- [ ] Deploy and troubleshoot microservices

## Month 3: Architect-Level Practice

### Week 9 - Advanced System Design
- [ ] Multi-region architecture
- [ ] Database replication and partitioning
- [ ] Distributed caching
- [ ] High availability and disaster recovery
- [ ] Backpressure and rate limiting
- [ ] Observability and security architecture
- [ ] Design a scalable order processing platform

### Week 10 - AI Architecture
- [ ] LLM fundamentals
- [ ] Tokens and context windows
- [ ] Embeddings and vector databases
- [ ] RAG architecture
- [ ] Spring AI
- [ ] Tool calling and MCP
- [ ] AI security and evaluation
- [ ] Build a document Q&A service

### Week 11 - Capstone Integration
- [ ] Integrate Spring Boot and Kafka
- [ ] Implement transactional outbox
- [ ] Containerize services
- [ ] Deploy to Kubernetes
- [ ] Integrate GCP
- [ ] Add observability
- [ ] Run load and failure tests

### Week 12 - Architecture Interviews
- [ ] Practice HLD and LLD
- [ ] Perform capacity estimation
- [ ] Defend architecture trade-offs
- [ ] Review security and cost
- [ ] Revise Java and DSA
- [ ] Complete two architecture mock interviews
- [ ] Complete one coding mock interview

### Week 13 - Final Assessment
- [ ] Complete architecture documentation
- [ ] Create C4 and sequence diagrams
- [ ] Prepare architecture decision records
- [ ] Present a 30-minute architecture review
- [ ] Prepare architect-focused resume
- [ ] Identify target architect roles
- [ ] Complete final readiness assessment

## Weekly Review Checklist

- [ ] Explain concepts without notes
- [ ] Complete hands-on exercises
- [ ] Review architectural trade-offs
- [ ] Complete a ChatGPT knowledge assessment
- [ ] Record knowledge gaps
- [ ] Update the learning journal
- [ ] Plan the next week
